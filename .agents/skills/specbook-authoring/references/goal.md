# Goal: プロダクトが目指す状態

**置き場所:** `docs/goals/`。**Type:** `goal`。**必須relation:** なし。

永続的に目指す状態やプロダクトレベルの成功基準を表すときに Goal を作る。実装機能の一覧やタスクのロードマップとして使わない。

## 推奨する内容

- **目指す状態:** 誰が恩恵を受け、何が変わり、なぜ大事か。
- **対象範囲:** 目指す状態の内側と外側は何か。
- **達成の指標:** 観測可能な基準。数値は既知か明示的に目標として選んだ場合のみ。
- **制約・非目標:** 意図的に追わないもの。
- **未解決の問い:** 確定したこととして提示しない不確実さ。

requirement から Goal へのリンクは `requirement.relations.goal` キーで行う。Goal は生成された子一覧を保持しない。下位Goalは `relations.goal` キーで上位Goalを指し、本文で親子関係である旨を明記する。

## レビュー

目指す状態が観測できない曖昧なスローガンは却下する。実装が終わったことだけを根拠に成功を宣言しない。プロダクトの作り直しでは、目指す状態が実際に不明確か変化している場合にだけここから始める。
