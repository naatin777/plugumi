# 実装規約

コードを書く・依存を増やす前に読む。

## 外部依存

- **ライブラリ・パッケージを追加する前に、必ずユーザーの許可を取る。** 使いたいライブラリ名・目的・代替（標準ライブラリで足りるか）を提示して確認する
- 標準ライブラリで実現できるなら標準ライブラリを優先する（依存を最小化する方針）
- Go設定ファイルは外部TOMLではなく `encoding/json` を使う（`plugumi.json`）

## 可読性

- **人間が読みやすいコードを優先する。** 賢い仕組み（間接的なhelper・反射的な登録機構）より、素直な構造（plainな関数・明示的な分岐）を選ぶ
- プロトコル由来の値・形にはコメントで出典を添える（例: `{accepted:true}` は contracts/00003 の受理response）
- ファイル冒頭にそのファイルがプロトコルのどの部分を担うか一言添える
